# Quickstart: Initial Application Foundation

## Prerequisites
- Node.js LTS, npm/pnpm.

## Setup
1. Install dependencies.
2. Copy `.env.example` to `.env` (optional; no mandatory vars for foundation).
3. Run dev server.

## Validation
- Dev server starts and shell renders.
- Navigate routes; unknown route shows not-found.
- Run lint/format: zero errors.
- Run tests: pass.
- Pre-commit and pre-push hooks execute.
- CI passes.
- Accessibility: automated checks pass; manual keyboard navigation verified.
- Responsive: shell usable on desktop and mobile.
